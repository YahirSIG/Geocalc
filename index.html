Formatos de Archivo

Sube archivos .txt o .csv. El sistema detecta el formato según las columnas:

A) Geográficas (2 columnas)

Latitud, Longitud (en decimales).

16.7532, -93.1145
16.7540, -93.1150
B) UTM (3 columnas)

Vértice, Este (X), Norte (Y).

P-1, 487500.23, 1852000.45
P-2, 487600.10, 1852100.12

¡Ojo! Para UTM, el sistema usará la Zona y Hemisferio que tengas seleccionados en la pantalla principal.
